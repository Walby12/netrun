# netrun
 
**netrun** is a lightweight, high-performance cyberpunk environment built from the ground up in C. It utilizes a custom raycasting engine to simulate a pseudo-3D "deck-running" experience, inspired by 90s dungeon crawlers and retro-futurist aesthetics.

> [!WARNING]  
> **Status: Early Development.** netrun is currently an experimental project. The internal architecture and API are subject to frequent, breaking changes.

## Prerequisites

To build and run **netrun**, you need:

1.  **C Compiler:** `gcc` (C99 support required).
2.  **GPU Hardware:** Graphics card.
3.  **Internet Access:** (Planned for future releases).
